# Task 18 — Missing Values in Pandas

## Task
Identify missing values in a dataset and practice handling them using dropping and filling techniques.

## Objective
Understand one of the most common data preprocessing problems.

## Tools
- Python
- Pandas
- Jupyter Notebook

## Deliverables
1. Missing-value summary
2. Examples using `isna()` and `notna()`
3. A cleaned version of the dataset

## Main Topics
- Missing-value concept
- `isna()` and `notna()`
- Missing-value counting
- `dropna()`
- `fillna()`
- Mean, median and mode
- Choosing a suitable strategy
- Validation after cleaning
- Practical student-data preprocessing

## Recommended Strategy in This Project
- Numerical columns: median
- Categorical columns: mode
